Frames for the interface (not the cards, logos or playmats).
  Window.png: around windows (Settings, game over, the menus, the tutorial notes...), tinted gold
  Button.png: around every button, tinted a faint white
White line art on a see-through background; the game finds where the corners end and stretches the straight middle.
Swap in any other border by saving it under the same name; delete a file to have no frame.

From Kenney's Fantasy UI Borders (www.kenney.nl), Creative Commons Zero (CC0):
  Window.png is PNG/Double/Border/panel-border-000.png, Button.png is panel-border-009.png.
