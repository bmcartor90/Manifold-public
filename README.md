# Manifold: learn to play

Manifold's tutorial, played in a web browser: **https://bmcartor90.github.io/Manifold-public/**

This repository is only the published game (a Unity Web build, served by GitHub Pages). It's made from the game's
own repository: in Unity, **Manifold > Build web tutorial...**, choosing this repository's folder, replaces
everything here but this README; then commit and push, and the page has it a minute later. (How it's made, and how
it's shown on MountBakerGames.com: docs/Web-Tutorial.md in the game's repository.)
